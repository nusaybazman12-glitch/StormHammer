# LoadTest v3.0 - অ্যাডভান্সড লোড টেস্টিং টুল

## 📖 বর্ণনা
LoadTest একটি শক্তিশালী ও সহজ লোড টেস্টিং টুল যা আপনার ওয়েবসাইটের পারফরম্যান্স যাচাই করে।

## ⚠️ সতর্কতা
**শুধুমাত্র আপনার নিজের ওয়েবসাইটে ব্যবহার করুন!** অননুমোদিত ব্যবহার আইনত শাস্তিযোগ্য।

## 📋 প্রয়োজনীয়তা
- Node.js v16+
- npm

## ⚙️ ইনস্টলেশন
```bash
# 1. ফোল্ডার তৈরি
mkdir LoadTest
cd LoadTest

# 2. package.json তৈরি
npm init -y

# 3. ডিপেন্ডেন্সি ইনস্টল
npm install axios chalk

# 4. loadtester-simple.js ফাইল তৈরি করুন
# (উপরের কোড কপি-পেস্ট করুন)
